# Final release — 11 September 2026

The proofreading changes are deployed on both public sites. This document and the current README supersede the wording and release instructions in the earlier review reports.

## Final wording

- **Deposits:** “Deposit $100 USDC or more.” A $150 deposit is valid; rounding of the protocol headline is a display convention, not a deposit-size restriction.
- **Agent role:** research verified access terms and live CMC data, then draft unsigned transactions for the user to review and sign. Execution proposals in this app target Avalanche.
- **IXS figures:** the headline is protocol TVL sourced from rwa.io via VaultTerms. Daily Avalanche and BNB vault balances are shown separately. Check the BNB route for its own terms and rewards.
- **Market comparisons:** compare issuer wrappers against CMC’s blended tokenized average. A primary-exchange comparison requires an actual reference quote.
- **Site descriptions:** neutral wording, with accurate data sources and software attribution.
